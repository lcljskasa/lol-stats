# LOL 战绩速览

英雄联盟桌面小工具：选英雄时自动查队友战绩，推荐对位英雄、符文和出装，还有版本梯队榜和单局详情评分。

## 功能

- **队伍**：进入选英雄自动弹出，显示每个队友的段位、胜率、KDA、最近 10 场、常用英雄，卡片背景是英雄原画。点卡片看完整对局列表。
- **我的**：位置分布、胜率走势、常一起玩的人、英雄数据表（胜率 / KDA / 分均补刀 / 场均伤害）、最近对局。
- **出装 · 对位**：
  - 自动识别对面和你对线的英雄，推荐打它胜率最高的英雄
  - 针对这个对手的符文、出装、召唤师技能、技能加点（不选对手就是全部对局的通用推荐）
  - 一键把符文导入客户端（只会新建或覆盖名字以「速览」开头的符文页）
  - 难打 / 好打的对手、版本胜率走势
- **梯队**：各位置英雄的梯队、胜率、选取率、禁用率、排名变化，也有大乱斗榜。
- **单局详情**：点任意一局，看双方 10 人的伤害、经济、补刀、视野、装备和评分（MVP / ACE）。

## 使用

1. 登录英雄联盟客户端。
2. 双击 `dist\LOLStats.exe`（单文件，不需要装 Python）。
3. 进入选英雄后窗口会自动弹到最前面。

「出装 · 对位」和「梯队」不开客户端也能用。如果提示「没找到客户端」：国服客户端一般以管理员身份运行，右键 exe → 以管理员身份运行。

## 数据来源

| 数据 | 来源 |
|---|---|
| 战绩、段位、对局详情、选英雄信息 | 客户端本地接口（LCU API），只读 |
| 出装、符文、对位、梯队 | OP.GG 网站背后的接口（非官方，League Akari 也在用），全球服数据，30 分钟缓存 |
| 英雄 / 装备 / 符文的名称和图标 | 优先客户端；没开客户端时用 CommunityDragon（公开的素材镜像） |

单局评分是本程序自己算的：KDA、参团率、伤害、经济、视野、补刀加权后在本局内归一化，思路参考 OP Score，不是 OP.GG 官方分数。

## 开发

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

打包：运行 `build.bat`，生成 `dist\LOLStats.exe`。

### 文件

- `lcu.py`：连接客户端、分页并发拉战绩、本地缓存、单局详情和评分、导入符文
- `opgg.py`：OP.GG 出装、对位、梯队
- `assets.py`：名称和图标（客户端优先，CommunityDragon 兜底）
- `app.py`：后台线程、本地网页服务、窗口
- `web/index.html`：界面
- `mock_lcu.py`、`test-with-mock.bat`：模拟客户端，没开游戏时测试用

### 离线测试

`test-with-mock.bat` 会启动模拟客户端并打开界面。想看到真实英雄原画，可以把官方 Data Dragon 的图片放进 `mock_assets/`
（文件名如 `145_load.jpg`、`145_square.png`、`145_splash.jpg`），没有的英雄会自动去 CommunityDragon 拿头像。

## 注意

- 只读取客户端本来就能看到的信息，排位里被隐藏的对手名字不会查。唯一的写操作是你手动点「导入到客户端」。
- 本地网页接口只接受本机请求，并校验启动时生成的令牌，其他网页无法调用。
- 国服（腾讯）对第三方程序检测较严，建议先在小号上试。
- OP.GG 接口是非官方的，对方改版时出装和梯队可能暂时失效。
- 本项目与 Riot Games、腾讯、OP.GG 无关。英雄联盟及相关图片版权归 Riot Games 所有。
