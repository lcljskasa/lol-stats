# LOL 战绩速览

英雄联盟桌面小工具：选英雄时自动查队友战绩，推荐对位英雄、符文和出装，还有版本梯队榜和单局详情评分。

## 下载

- 国内推荐：Gitee 发行版 https://gitee.com/lclplm/lol-stats/releases
- GitHub：https://github.com/lcljskasa/lol-stats/releases/latest

## 功能

- **队伍**：进入选英雄自动弹出，显示每个队友的段位、胜率、KDA、最近 10 场、常用英雄，卡片背景是英雄原画。点卡片看完整对局列表。
- **我的**：位置分布、胜率走势、常一起玩的人、英雄数据表（胜率 / KDA / 分均补刀 / 场均伤害）、最近对局。
- **出装 · 对位**：
  - 自动识别对面和你对线的英雄，推荐打它胜率最高的英雄
  - 针对这个对手的符文、出装、召唤师技能、技能加点（不选对手就是全部对局的通用推荐）
  - 选人时自动导入：在客户端选定英雄后，自动写入推荐符文（能识别对位时用针对对手的版本）和召唤师技能，闪现保持原来的键位
  - 符文树可以直接点选修改（含切换主系 / 副系），改动实时同步到客户端；召唤师技能可以一键「使用」
  - 符文页命名为「速览 英雄名」，只会新建或覆盖这一页，不动你自己的符文页；以上写入功能都可以在出装页关掉
  - 难打 / 好打的对手、版本胜率走势
- **梯队**：各位置英雄的梯队、胜率、选取率、禁用率、排名变化，也有大乱斗榜。
- **游戏内悬浮窗**：进游戏自动出现在屏幕右侧，对局结束自动隐藏，不会抢游戏焦点。显示双方装备经济差、推荐出装（已买的打勾、下一件还差多少钱）、下一个该升的技能、敌方治疗来源与我方重伤提醒、控制守卫数量、敌方阵亡倒计时。可折叠，也可以本局关闭；主窗口标题栏的「悬浮窗」按钮可以整体关掉。**游戏需设为无边框或窗口模式**，全屏模式下任何悬浮窗都盖不上去。
- **单局详情**：点任意一局，看双方 10 人的伤害、经济、补刀、视野、装备和评分（MVP / ACE）。

## 使用

1. 登录英雄联盟客户端。
2. 双击 `LOLStats.exe`（单文件，不需要装 Python）。程序会自动请求管理员权限（国服客户端以管理员身份运行，需要同等权限才能读到），第一次运行会在桌面创建「LOL战绩速览」快捷方式。
3. 进入选英雄后窗口会自动弹到最前面。

- 每人查最近 1000 场（客户端存不了那么多时有多少显示多少），对局列表先显示 40 场，可以点「显示更多」。
- 点「—」缩到右下角托盘，进入选英雄时自动弹出；托盘图标右键可以显示主窗口、开关悬浮窗、退出。点「×」直接退出。
- 缩到托盘时界面会卸载以释放内存；悬浮窗只在对局中加载。
- 「出装 · 对位」和「梯队」不开客户端也能用。
- 进入加载界面时窗口自动弹出，显示双方 10 人（上下按位置对齐）；游戏正式开始后自动缩回托盘，换成悬浮窗。托盘菜单可关闭「加载时自动弹出 10 人」。排位选英雄时 Riot 会隐藏对面身份，本程序不去还原，只显示我方 5 人；对面身份公开的模式在选英雄时就显示 10 人。
- 只能同时开一个；再双击会打开已在运行的那个。程序数据保存在 `%LOCALAPPDATA%\LOLStats`，exe 旁边不会生成文件。
- 有新版本时左下角出现下载按钮。

## 数据来源

| 数据 | 来源 |
|---|---|
| 战绩、段位、对局详情、选英雄信息 | 客户端本地接口（LCU API），只读 |
| 出装、符文、对位、梯队 | OP.GG 网站背后的接口（非官方，League Akari 也在用），全球服数据，30 分钟缓存 |
| 悬浮窗的游戏内数据 | Riot 官方的 Live Client Data API（游戏运行时本机 2999 端口，只读） |
| 英雄 / 装备 / 符文的名称和图标 | 优先客户端；没开客户端时用 CommunityDragon（公开的素材镜像） |

单局评分是本程序自己算的：KDA、参团率、伤害、经济、视野、补刀加权后在本局内归一化，思路参考 OP Score，不是 OP.GG 官方分数。

## 开发

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

打包：运行 `build.bat`，生成 `dist\LOLStats.exe`。

### 文件

- `lcu.py`：连接客户端、分页并发拉战绩、本地缓存、单局详情和评分、导入符文
- `opgg.py`：OP.GG 出装、对位、梯队
- `live.py`：游戏内实时数据（经济、治疗 / 重伤、控制守卫）
- `web/overlay.html`：游戏内悬浮窗界面
- `assets.py`：名称和图标（客户端优先，CommunityDragon 兜底）
- `app.py`：后台线程、本地网页服务、窗口、托盘、桌面快捷方式
- `tray.py`：系统托盘图标
- `web/index.html`：界面
- `mock_lcu.py`、`test-with-mock.bat`：模拟客户端，没开游戏时测试用

### 离线测试

`test-with-mock.bat` 会启动模拟客户端并打开界面。测试悬浮窗：先用 `set MOCK_PHASE=InProgress` 启动 `mock_lcu.py`（模拟游戏中），再运行 `test-overlay.bat`。想看到真实英雄原画，可以把官方 Data Dragon 的图片放进 `mock_assets/`
（文件名如 `145_load.jpg`、`145_square.png`、`145_splash.jpg`），没有的英雄会自动去 CommunityDragon 拿头像。

## 注意

- 只读取客户端本来就能看到的信息，排位里被隐藏的对手身份不会还原。写入客户端的只有符文页和召唤师技能（自动导入、实时同步、手动导入），都可以关掉。
- 本地网页接口只接受本机请求，并校验启动时生成的令牌，其他网页无法调用。
- 国服（腾讯）对第三方程序检测较严，建议先在小号上试。
- OP.GG 接口是非官方的，对方改版时出装和梯队可能暂时失效。
- 本项目与 Riot Games、腾讯、OP.GG 无关。英雄联盟及相关图片版权归 Riot Games 所有。
